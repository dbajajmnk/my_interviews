# 8. Google Interview Drill

Capstone: Design a multi-tenant enterprise document + support platform using React, Java/Spring Boot, SQL, object storage, RAG/LLM, and ticket/order tools. Cover security, scale, resilience, evaluation, observability, and rollout.

### Required Response Flow

> **Clarify → First Approach → Improve → Code/Design → Test → Edge Cases → Complexity/Cost → Failure → Trade-Off → Follow-Up → Defend**

# 9. Day-Level Common Mistakes

- Technology dumping
- No client clarification
- Rewrite recommendation without evidence
- AI owns authorization
- Ignoring operational cost

---

# 10. Day-Level Best Practices

- Business goal first
- State assumptions
- Use progressive design
- Defend trade-offs
- Separate mitigation from long-term fix
- No bluffing
