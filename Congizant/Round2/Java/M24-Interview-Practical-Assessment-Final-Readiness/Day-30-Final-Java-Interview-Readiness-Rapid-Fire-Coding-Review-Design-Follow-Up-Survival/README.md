# 8. Google Interview Drill

Design a secure, scalable Java/Spring Boot order platform with async fulfillment and an optional AI support assistant. Start with requirements, then data/API, scale, security, resilience, observability, and trade-offs.

### Required Response Flow

> **Clarify → First Approach → Improve → Code/Design → Test → Edge Cases → Complexity/Cost → Failure → Trade-Off → Follow-Up → Defend**
