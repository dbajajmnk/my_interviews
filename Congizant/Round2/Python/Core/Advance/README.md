# 1. Pack Objective

PY-02 validates that you can use Python as an engineering language, not merely write scripts.

By the end of this pack you should be able to:

- design clean Python object models;
- explain Python inheritance, MRO, composition, and abstraction;
- use dataclasses appropriately;
- explain and implement decorators;
- explain iterators and generators;
- use context managers for deterministic resource handling;
- use type hints, ABCs, protocols, and structural typing;
- apply SOLID without copying Java-style design blindly;
- explain relevant GoF patterns in Python;
- recognize when Python language features make a classical pattern unnecessary;
- review over-engineered Python designs;
- survive architect-level trade-off and production follow-ups.

Target:

> **Understand → Explain → Apply → Code → Debug → Review → Design → Defend**
