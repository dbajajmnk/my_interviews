# 1. Pack Objective

PY-04 converts Python knowledge into interview execution.

By the end of this pack you should be able to:

- solve coding problems using a repeatable Google-level reasoning method;
- analyze time and space complexity;
- use arrays/lists, strings, dictionaries, sets, two pointers, sliding window, stack, queue, recursion, trees, and graph basics;
- move from brute force to an optimized solution;
- test normal and edge cases explicitly;
- debug broken Python code systematically;
- review code for correctness, readability, maintainability, security, performance, and concurrency risks;
- refactor over-complicated Python code;
- evaluate AI-generated Python code instead of trusting it blindly;
- explain why a solution is correct;
- survive follow-up changes to requirements.

Target:

> **Clarify → Model → Brute Force → Improve → Code → Test → Analyze → Review → Defend**

# 5. Coding Interview Standard

For every coding problem:

```text
1. Restate problem
2. Clarify constraints
3. Give simple/brute-force approach
4. Analyze complexity
5. Identify better data structure/pattern
6. Explain optimized approach
7. Code cleanly
8. Test with normal case
9. Test edge cases
10. State final complexity
11. Handle interviewer follow-up
```

Never jump straight into code.
