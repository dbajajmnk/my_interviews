# Context Security and Privacy

## Risks

- secrets leaked to model;
- cross-tenant memory;
- PII over-collection;
- excessive retention;
- unauthorized retrieval.

## Controls

- data minimization;
- field-level filtering;
- tenant namespaces;
- encryption;
- retention/deletion;
- redaction;
- model/provider policy.

## Rule

Context should follow least-privilege principles just like tool permissions.
