# Threat Model for AI Agents

## Threat Actors

- malicious user;
- compromised tool;
- poisoned document;
- compromised model/provider;
- insider;
- cross-tenant attacker.

## Assets

- secrets;
- PII;
- business data;
- privileged tools;
- money;
- customer communications.

## Rule

Threat-model agent actions, not just chat messages.
