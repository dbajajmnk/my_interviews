# Enterprise Agent Security Checklist

## Checklist

- [ ] Threat model documented
- [ ] Trust boundaries defined
- [ ] Authentication enforced
- [ ] Authorization enforced server-side
- [ ] Tenant isolation tested
- [ ] Tool risk tiers assigned
- [ ] Scoped credentials used
- [ ] Prompt injection tests
- [ ] Indirect injection tests
- [ ] RAG ACL/provenance controls
- [ ] Memory write/read policy
- [ ] Secret handling policy
- [ ] PII minimization/redaction
- [ ] Structured/business validation
- [ ] HITL for high-risk actions
- [ ] Sandbox for code execution
- [ ] Egress restrictions
- [ ] Rate limits/quotas
- [ ] Audit logging
- [ ] Security telemetry
- [ ] Incident response runbook
- [ ] Model/provider governance
- [ ] Tool owner/governance
- [ ] Data retention policy
- [ ] Red-team coverage
