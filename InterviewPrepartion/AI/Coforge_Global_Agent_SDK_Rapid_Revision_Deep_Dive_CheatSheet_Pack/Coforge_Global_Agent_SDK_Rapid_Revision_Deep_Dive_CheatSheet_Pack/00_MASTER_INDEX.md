# Coforge + Global Agent SDK Rapid Revision — Master Index

## Purpose

This is the final rapid-revision pack before the full mock interview.

It condenses the entire preparation journey into interview-ready answers for a Senior Software Engineer / Agent SDK & Developer Enablement role, while keeping the material reusable for global Senior, Staff, Lead, Principal, and Agent Platform opportunities.

## Role Focus

Primary role themes:
- multi-language Agent SDK design and maintenance;
- reusable frameworks, scaffolds, and templates;
- API / SDK interfaces;
- versioning and backward compatibility;
- LLM provider integrations;
- tools, memory, vector databases, observability;
- tool calling, structured output, streaming, context management, orchestration;
- evaluation and testing;
- CI/CD;
- developer enablement;
- reliability, performance, and security;
- Python plus Java/C#/TypeScript;
- OpenTelemetry;
- Microsoft Foundry / Azure AI Foundry.
