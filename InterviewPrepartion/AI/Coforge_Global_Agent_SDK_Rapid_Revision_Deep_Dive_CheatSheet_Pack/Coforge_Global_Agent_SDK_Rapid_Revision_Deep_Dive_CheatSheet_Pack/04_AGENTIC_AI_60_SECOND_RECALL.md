# Agentic AI — 60-Second Recall

## Formula

```text
Agent = Model + Instructions + Context + State + Tools + Memory + Guardrails + Observability
```

## 60-Second Answer

> An agent is more than an LLM response. It is a system that can interpret a goal, decide what to do next, use tools, observe results, update state, and continue until a terminal condition. For enterprise use, I keep deterministic controls around the agentic core: auth, policy, tool execution, side effects, approval, and audit.

## Recall Points

- RAG is not memory.
- Workflow is not automatically an agent.
- Single agent first.
- HITL for high-risk actions.
