# Agent Memory — 60-Second Recall

## Formula

```text
Working + Short-Term + Long-Term(Semantic/Episodic/Procedural)
```

## 60-Second Answer

> Memory is what the system deliberately retains for later use. Working memory supports the current task, short-term memory covers the thread/session, and long-term memory persists selected facts, experiences, or procedures. I use explicit read/write/forget policies, provenance, freshness, conflict handling, and tenant isolation.

## Recall Points

- Memory != RAG.
- Memory != runtime state.
- Write selectively.
- Forgetting is first-class.
