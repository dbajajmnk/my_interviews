# Agentic RAG — 60-Second Recall

## Formula

```text
Need Detection + Query Rewrite + Retrieve + Rerank + Evidence Check + Ground + Provenance
```

## 60-Second Answer

> Agentic RAG makes retrieval a controlled decision rather than an unconditional pipeline step. The agent determines when retrieval is needed, can rewrite/decompose queries, choose a retriever, rerank evidence, iterate if evidence is insufficient, and answer with provenance.

## Recall Points

- Retrieval only when needed.
- ACL filters.
- Separate retrieval eval from answer eval.
- Groundedness + citations.
