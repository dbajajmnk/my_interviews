# Agent Orchestration — 60-Second Recall

## Formula

```text
Plan + Route + Delegate + Coordinate + State + Recover + Terminate
```

## 60-Second Answer

> I choose orchestration patterns according to control needs: single-agent, sequential, parallel, router, supervisor, planner-executor, handoff, or explicit workflow/DAG. I prefer the simplest pattern that makes state and termination clear.

## Recall Points

- Multi-agent is not automatically better.
- Termination must be explicit.
- Agent-as-tool differs from handoff.
- State propagation must be controlled.
