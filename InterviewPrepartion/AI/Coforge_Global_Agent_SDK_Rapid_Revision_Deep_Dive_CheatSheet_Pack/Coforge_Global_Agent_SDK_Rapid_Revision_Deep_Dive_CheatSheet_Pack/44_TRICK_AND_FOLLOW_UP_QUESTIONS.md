# Trick and Follow-Up Questions

## Watch For

- “Why not just use LangChain?”
- “Why do we need our own SDK?”
- “Why multi-agent?”
- “Why not retry everything?”
- “Why not store entire chat history as memory?”
- “Why not log every prompt?”
- “Why not expose provider types?”
- “Why not use model output for authorization?”
- “Why do we need fencing if we already have a lock?”
- “Why not make every field required?”

## Answer Pattern

Explain the hidden operational or compatibility trade-off, then give the safer production design.
