# Bad Answers to Avoid

## Avoid

- “LangChain handles everything.”
- “Multi-agent is always better.”
- “RAG is memory.”
- “JSON output means it is safe.”
- “We can just retry.”
- “Authentication means the user can call the tool.”
- “If the lease expires the old worker stops.”
- “Streaming means tokens.”
- “The SDK API should expose everything for flexibility.”
- “We can update prompts directly in production.”

## Replace With

Precise engineering boundaries, explicit trade-offs, and operational controls.
