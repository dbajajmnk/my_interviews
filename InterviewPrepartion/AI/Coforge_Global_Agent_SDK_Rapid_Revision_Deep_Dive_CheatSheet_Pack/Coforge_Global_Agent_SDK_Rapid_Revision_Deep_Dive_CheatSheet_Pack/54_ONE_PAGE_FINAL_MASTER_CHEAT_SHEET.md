## Ten Rules

1. Stable contract outside; modular intelligence inside.
2. Model proposes; trusted code authorizes and executes.
3. State, context, memory, and RAG are different.
4. Use simplest orchestration that works.
5. Structured output controls shape, not truth.
6. Stream semantic execution events.
7. Test deterministic logic; evaluate probabilistic behavior.
8. One user goal → one correlated trace.
9. Retry safely: timeout, idempotency, checkpoint, fencing.
10. Version everything that changes behavior.

## Final 30-Second Answer

> I design Agent SDKs as enterprise developer platforms: a small stable multi-language contract over a modular runtime, provider adapters for models, governed tool execution, separate context/memory/RAG layers, explicit orchestration and durable state, semantic streaming, HITL for high-risk actions, OpenTelemetry, evaluation, deterministic testing, security, reliability, backward compatibility, CI/CD, and strong developer enablement.
