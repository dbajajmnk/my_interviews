# Task Success Metrics

## Examples

- resolved correctly;
- required action completed;
- expected artifact produced;
- correct ticket routed;
- correct report generated;
- user goal achieved.

## Binary vs Graded

Binary:
```text
success / failure
```

Graded:
```text
0.0 – 1.0
```

## Rule

Task success is often the most important top-level metric.
