# LLM-as-Judge

## Use

Useful for subjective criteria such as:
- clarity;
- completeness;
- groundedness;
- relevance;
- helpfulness.

## Judge Prompt

Define:
- rubric;
- score scale;
- evidence;
- examples;
- output schema.

## Risk

Judges may have:
- bias;
- inconsistency;
- verbosity preference;
- self-preference;
- position bias.

## Rule

Calibrate model judges against human judgments and deterministic signals.
