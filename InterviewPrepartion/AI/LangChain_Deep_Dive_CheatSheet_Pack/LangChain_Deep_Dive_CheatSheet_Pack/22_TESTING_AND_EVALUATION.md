# Testing and Evaluation

## Unit Testing

Test:
- tools;
- middleware;
- context assembly;
- structured-output schemas;
- routing policies.

## Agent Testing

Test:
- expected tool selection;
- tool arguments;
- stop behavior;
- memory updates;
- failure paths;
- policy behavior.

## Evaluation Metrics

- task completion;
- groundedness;
- tool accuracy;
- retrieval quality;
- latency;
- cost;
- safety;
- escalation rate.

## Testability Rule

Inject model/tool dependencies and use deterministic fakes where possible.
