# Testing and Evaluation

## Unit Testing

Test:
- function tools;
- middleware;
- context providers;
- executors;
- routing conditions.

## Integration Testing

Test:
- session continuity;
- provider behavior;
- workflow paths;
- A2A failures;
- checkpoint/resume;
- tool approval.

## Evaluation

Measure:
- task success;
- tool correctness;
- orchestration correctness;
- groundedness;
- latency;
- cost;
- safety;
- human escalation rate.

## Rule

Test deterministic workflow logic separately from probabilistic model quality.
