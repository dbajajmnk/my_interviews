## Important Current Facts

Current Microsoft documentation states that:
- Agent Framework is the direct successor to Semantic Kernel and AutoGen agent work.
- Core agent concepts are model/remote agent, instructions, tools, middleware, context providers, and session state behind a common run interface.
- Workflows provide explicit graph-based orchestration with executors, edges, state, checkpoints, and HITL.
- Built-in orchestrations include sequential, concurrent, handoff, group chat, and Magentic.
- Agent Harness provides opinionated scaffolding for long multi-step tasks.
- A2A provides framework-agnostic remote agent communication.
- Current language documentation centers on C#, Python, and Go, with some features varying by language/preview status.
