# Canonical Cross-Language Contract

## Canonical Concepts

Define language-neutral concepts first:
- Agent;
- Tool;
- Run;
- RunContext;
- StreamEvent;
- Result;
- Error;
- Cancellation;
- Capability metadata.

## Artifact

Maintain a canonical specification describing:
- names;
- behavior;
- lifecycle;
- error semantics;
- wire formats;
- compatibility guarantees.
