# Testing and Evaluation

## Unit Tests

Test:
- function tools;
- guardrails;
- instructions builders;
- local context behavior;
- approval rules.

## Agent Tests

Test:
- expected tool selection;
- handoff destination;
- final output schema;
- interruption behavior;
- session continuity;
- failure paths.

## Evaluation

Measure:
- task success;
- tool correctness;
- handoff correctness;
- guardrail behavior;
- latency;
- token/cost;
- user satisfaction;
- safety.

## Tracing

Use traces as evidence for debugging failures and building regression datasets.
