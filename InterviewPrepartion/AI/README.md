# AI Interview Preparation Repository

This repository contains structured **AI, Agentic AI, Agent SDK, LLMOps, Enterprise AI Architecture, Security, Reliability, Observability, RAG, Evaluation, Testing, and System Design** cheat-sheet packs for interview preparation and deep technical revision.

The repository is organized so that you can move from **AI foundations → Agent SDK engineering → enterprise architecture → rapid revision → mock interview**.

For every folder:

1. Open `00_MASTER_INDEX.md`
2. Study the numbered files in sequence
3. Read the combined `*_COMPLETE_CheatSheet.md` for consolidation
4. Finish with the `*_ONE_PAGE_FINAL_CHEAT_SHEET.md`
5. Practice the interview/system-design questions
6. Move to the next pack only after you can explain the topic without reading
