# Reference SDK Versioning Policy

## Policy

- Stable APIs follow SemVer.
- Additive changes in MINOR.
- Fixes in PATCH.
- Breaking changes only in MAJOR.
- Deprecate at least one supported release before removal where practical.
- Preview APIs may change outside normal stability guarantees.
- Compatibility matrix published per release.

## Rule

Policy should be written before the first public release.
