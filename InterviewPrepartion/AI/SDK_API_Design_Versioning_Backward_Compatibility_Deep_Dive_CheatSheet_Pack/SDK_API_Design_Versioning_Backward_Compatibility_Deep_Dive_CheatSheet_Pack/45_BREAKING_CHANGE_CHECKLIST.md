# Breaking Change Checklist

## Checklist

- [ ] Is public API affected?
- [ ] Source compatibility checked
- [ ] Binary compatibility checked
- [ ] Behavioral compatibility checked
- [ ] Wire compatibility checked
- [ ] Event/stream compatibility checked
- [ ] Error compatibility checked
- [ ] Enum evolution checked
- [ ] Nullability/default changes checked
- [ ] Multi-language impact checked
- [ ] Can change be additive instead?
- [ ] Deprecation path available
- [ ] Compatibility shim considered
- [ ] Migration guide written
- [ ] Contract tests added
- [ ] Compatibility matrix updated
- [ ] Release notes updated
