# Amazon S3

## What

Durable object storage.

## Model

```text
Bucket
 └── Object
      ├── key
      ├── data
      └── metadata
```

## Uses

```text
data lake
static assets
backup
logs
documents
media
artifacts
```

## Important Features

```text
versioning
lifecycle
replication
encryption
Object Lock
event notifications
```

## Trap

S3 is object storage, not a traditional mounted block/file system.
