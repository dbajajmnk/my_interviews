# Iframes

## Strong Isolation

```text
DOM isolation
CSS isolation
JavaScript isolation
origin security boundary
```

## Good Fits

- third-party apps
- legacy systems
- high-security isolation
- embedded tools

## Costs

- communication complexity
- UX integration
- accessibility
- routing
- height/layout
- performance

## Trap

Iframes are not inherently bad; they are a strong isolation tool with integration costs.
