# Metrics / SLI / SLO

## Golden Signals

```text
Latency
Traffic
Errors
Saturation
```

## SLI

Measured indicator.

Example:

```text
successful request %
```

## SLO

Target.

Example:

```text
99.9% success over 30 days
```

## Error Budget

Allowed unreliability.

## Trap

SLO should reflect user/business outcomes, not only infrastructure uptime.
