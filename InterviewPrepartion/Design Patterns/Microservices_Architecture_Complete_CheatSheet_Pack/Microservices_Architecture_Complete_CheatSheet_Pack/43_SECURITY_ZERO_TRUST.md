# Security / Zero Trust

## Principle

Never trust network location alone.

## Service-to-Service

```text
mTLS
workload identity
least privilege
authorization
```

## External

```text
OAuth2 / OIDC
JWT / opaque token
API Gateway
rate limiting
```

## Data

```text
encryption at rest
encryption in transit
secret management
audit
```

## Trap

Authentication does not equal authorization.
