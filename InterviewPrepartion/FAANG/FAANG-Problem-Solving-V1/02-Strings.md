# Strings — 20 Exercises

## Fluency

### Q01

**Program Objective**

Write a program to reverse a string.

**Input**

```text
hello
```

**Output**

```text
olleh
```

### Q02

**Program Objective**

Write a program to determine whether a string is a palindrome.

**Input**

```text
madam
```

**Output**

```text
true
```

### Q03

**Program Objective**

Write a program to count the vowels in a string.

**Input**

```text
programming
```

**Output**

```text
3
```

### Q04

**Program Objective**

Write a program to count the number of words in a sentence.

**Input**

```text
FAANG coding builds strong problem solving
```

**Output**

```text
6
```

### Q05

**Program Objective**

Write a program to find the first character that appears exactly once in a string.

**Input**

```text
swiss
```

**Output**

```text
w
```

## Core

### Q06

**Input**

```text
programming
```

**Output**

```text
progamin
```

### Q07

**Program Objective**

Write a program to determine whether two strings contain exactly the same characters with the same frequencies.

**Input**

```text
String 1: listen
String 2: silent
```

**Output**

```text
true
```

### Q08

**Program Objective**

Write a program to find the longest common prefix among a list of strings.

**Input**

```text
["flower", "flow", "flight"]
```

**Output**

```text
fl
```

### Q09

**Program Objective**

Write a program to reverse the order of words in a sentence.

**Input**

```text
the sky is blue
```

**Output**

```text
blue is sky the
```

### Q10

**Program Objective**

Write a program to compress consecutive repeated characters using character counts.

**Input**

```text

```


## Interview

### Q11

**Program Objective**

Write a program to convert a string to a 32-bit signed integer by ignoring leading spaces, reading an optional sign and consecutive digits, and clamping overflow to the 32-bit signed range.

**Input**

```text
   -42
```

**Output**

```text
-42
```

### Q12

**Program Objective**

Write a program to find the longest palindromic substring. If multiple answers have the same maximum length, return the one with the earliest starting index.

**Input**

```text
babad
```

**Output**

```text
bab
```

### Q13

**Program Objective**

Write a program to find the zero-based index of the first occurrence of a pattern inside a source string, or -1 if the pattern is absent.

**Input**

```text
Source: sadbutsad
Pattern: sad
```

**Output**

```text
0
```

### Q14

**Program Objective**

Write a program to multiply two non-negative integers supplied as decimal strings and return the product as a decimal string.

**Input**

```text
Number 1: 123
Number 2: 456
```

**Output**

```text
56088
```

### Q15

**Program Objective**

Write a program to group words that contain identical character frequencies. Preserve input order inside each group and order groups by the first word that creates each group.

**Input**

```text
["eat", "tea", "tan", "ate", "nat", "bat"]
```

**Output**

```text
[["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]
```

### Q16

**Program Objective**

Write a program to determine whether one string can be formed by rotating another string.

**Input**

```text
String 1: ABCD
String 2: CDAB
```

**Output**

```text
true
```
