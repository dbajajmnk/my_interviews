# Hashing — 20 Exercises

## Fluency

### Q01

**Program Objective**

Write a program to count the frequency of each integer in an array and print entries in order of first appearance.

**Input**

```text
[1, 2, 2, 3, 3, 3]
```

**Output**

```text
1:1
2:2
3:3
```

### Q02

**Program Objective**

Write a program to count the frequency of each character in a string and print entries in order of first appearance.

**Input**

```text
banana
```

**Output**

```text
b:1
a:3
n:2
```

### Q03

**Program Objective**

Write a program to return the values that appear more than once in an integer array, sorted in ascending order.

**Input**

```text
[1, 2, 3, 2, 4, 1]
```

**Output**

```text
[1, 2]
```

### Q04

**Program Objective**

**Input**

```text

```

**Output**

```text
4
```

### Q05

**Program Objective**

**Input**

```text

```

**Output**

```text
true
```
