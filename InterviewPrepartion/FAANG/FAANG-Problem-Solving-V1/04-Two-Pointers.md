# Two Pointers — 20 Exercises

## Fluency

### Q01

**Program Objective**

Write a program to reverse an integer array in place.

**Input**

```text
[1, 2, 3, 4, 5]
```

**Output**

```text
[5, 4, 3, 2, 1]
```

### Q02

**Program Objective**

Write a program to determine whether a string is a palindrome after ignoring non-alphanumeric characters and letter case.

**Input**

```text
"A man, a plan, a canal: Panama"
```

**Output**

```text
true
```

### Q03

**Program Objective**

Write a program to find two values in a sorted integer array whose sum equals a target.

**Input**

```text
Array: [1, 2, 3, 4, 6]
Target: 6
```

**Output**

```text
[2, 4]
```

### Q04

**Program Objective**

Write a program to remove duplicate values from a sorted array.

**Input**

```text
[1, 1, 2, 2, 3]
```

**Output**

```text
[1, 2, 3]
```

### Q05

**Program Objective**

Write a program to move all zero values to the end while keeping non-zero values in their original relative order.

**Input**

```text
[0, 1, 0, 3, 12]
```

**Output**

```text
[1, 3, 12, 0, 0]
```

## Core

### Q06

**Program Objective**

Write a program to merge two sorted arrays into one sorted array.

**Input**

```text
Array 1: [1, 3, 5]
Array 2: [2, 4, 6]
```

**Output**

```text
[1, 2, 3, 4, 5, 6]
```

### Q07

**Program Objective**

Write a program to return the squares of a sorted integer array in sorted order.

**Input**

```text
[-4, -1, 0, 3, 10]
```

**Output**

```text
[0, 1, 9, 16, 100]
```

### Q08

**Program Objective**

Write a program to find all unique value pairs in a sorted array whose sum equals a target. Store each pair in ascending order and return pairs lexicographically.

**Input**

```text
Array: [1, 1, 2, 2, 3, 4, 5]
Target: 6
```

**Output**

```text
[[1, 5], [2, 4]]
```

### Q09

```text
String 1: ace
String 2: abcde
```

**Output**

```text
true
```

### Q10

**Program Objective**

**Input**

```text

```

**Output**

```text

```

## Interview

### Q11

**Program Objective**

Write a program to find all unique triplets whose sum equals zero. Store each triplet in ascending order and return triplets lexicographically.

**Input**

```text
[-1, 0, 1, 2, -1, -4]
```

**Output**

```text
[[-1, -1, 2], [-1, 0, 1]]
```

### Q12

**Program Objective**

Write a program to find the value pair whose sum is closest to a target. Return the pair in ascending order; if equally close pairs exist, return the lexicographically smallest pair.

**Input**

```text
Array: [-1, 2, 1, -4]
Target: 4
```

**Output**

```text
[1, 2]
```

### Q13

Write a program to find the maximum amount of water that can be contained between two vertical lines.

**Input**

```text
[1, 8, 6, 2, 5, 4, 8, 3, 7]
```

**Output**

```text
49
```

### Q14

**Program Objective**

Write a program to calculate the total units of rainwater trapped between elevation bars.

**Input**

```text
[4, 2, 0, 3, 2, 5]
```

**Output**

```text
9
```

### Q15

**Program Objective**

Write a program to stably partition an integer array so that all odd values appear before all even values while preserving relative order inside both groups.

**Input**

```text
[3, 1, 2, 4, 7, 6]
```

**Output**

```text
[3, 1, 7, 2, 4, 6]
```

### Q16

**Program Objective**

Write a program to find the minimum absolute difference between one value from each of two sorted arrays.

**Input**

```text
Array 1: [1, 2, 3, 11, 15]
Array 2: [8, 19, 23, 127, 235]
```

**Output**
