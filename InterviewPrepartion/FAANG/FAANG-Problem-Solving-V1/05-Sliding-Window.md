# Sliding Window — 20 Exercises

## Fluency

### Q01

**Program Objective**

Write a program to find the maximum sum of any contiguous subarray of size k.

**Input**

```text
Array: [2, 1, 5, 1, 3, 2]
k: 3
```

**Output**

```text
9
```

### Q02

**Program Objective**

Write a program to calculate the average of every contiguous subarray of size k.

**Input**

```text
Array: [1, 2, 3, 4, 5]
k: 3
```

**Output**

```text
[2.0, 3.0, 4.0]
```

### Q04

**Program Objective**

Write a program to find the largest number in each contiguous window of size k.

**Input**

```text
Array: [1, 3, -1, -3, 5, 3, 6, 7]
k: 3
```

**Output**

```text
[3, 3, 5, 5, 6, 7]
```

### Q05

**Program Objective**

**Input**

```text

k: 4
```

**Output**

```text

```
