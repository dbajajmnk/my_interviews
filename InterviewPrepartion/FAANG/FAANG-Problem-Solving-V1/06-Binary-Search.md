# Binary Search — 20 Exercises

## Fluency

### Q01

**Program Objective**

Write a program to find the index of a target value in a sorted integer array.

**Input**

```text
Array: [1, 3, 5, 7, 9]
Target: 5
```

**Output**

```text
2
```

```text

```
