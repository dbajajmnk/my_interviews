# Recursion — 10 Exercises

## Fluency

### Q01

**Program Objective**

Write a recursive program to calculate the factorial of a non-negative integer.

**Input**

```text
6
```

**Output**

```text
720
```

### Q02

**Program Objective**

Write a recursive program to calculate the nth Fibonacci number where F(0)=0 and F(1)=1.

**Input**

```text
7
```

**Output**

```text
13
```

### Q03

**Program Objective**

Write a recursive program to calculate the sum of the first n positive integers.

**Input**

```text
5
```

**Output**

```text
15
```

## Core

### Q04

**Program Objective**

Write a recursive program to reverse a string.

**Input**

```text
recursion
```

**Output**

```text
noisrucer
```

### Q05

**Program Objective**

Write a recursive program to calculate x raised to the power n for a non-negative exponent.

**Input**

```text
x: 2
n: 10
```

**Output**

```text
1024
```

### Q06

**Program Objective**

Write a recursive program to determine whether a string is a palindrome.

**Input**

```text
racecar
```

**Output**

```text
true
```

## Interview

### Q07

**Program Objective**

Write a recursive program to calculate the greatest common divisor of two positive integers.

**Input**

```text
48 18
```

**Output**

```text
6
```

### Q08

**Program Objective**

Write a recursive program to find the sum of all values in an integer array.

**Input**

```text
[4, 7, 2, 9]
```

**Output**

```text
22
```

### Q09

**Program Objective**

Write a recursive program to convert a positive decimal integer to its binary representation.

**Input**

```text
13
```

**Output**

```text
1101
```

## Advanced

### Q10

**Program Objective**

Write a recursive program to count how many different ways n stairs can be climbed by taking either 1 or 2 steps at a time.

**Input**

```text
5
```

**Output**

```text
8
```
