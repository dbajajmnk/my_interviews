# Bit Manipulation & Math — 20 Exercises

## Fluency

### Q01

**Program Objective**

Write a program to determine whether a positive integer is a power of two.

**Input**

```text
16
```

**Output**

```text
true
```

### Q02

**Program Objective**

Write a program to count the number of 1 bits in the binary representation of an unsigned integer.

**Input**

```text
11
```

**Output**

```text
3
```

### Q03

**Program Objective**

Write a program to find the integer that appears once when every other integer appears exactly twice.

**Input**

```text
[4,1,2,1,2]
```

**Output**

```text
4
```

### Q04

**Program Objective**

Write a program to find the missing number from values in the range 0 to n.

**Input**

```text
[3,0,1]
```

**Output**

```text
2
```

### Q05

**Program Objective**

Write a program to reverse the bits of a 32-bit unsigned integer.

**Input**

```text
43261596
```

**Output**

```text
964176192
```
