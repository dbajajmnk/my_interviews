# Base64 API

## Encoder

```java
String encoded =
    Base64.getEncoder()
          .encodeToString(data);
```

## Decoder

```java
byte[] decoded =
    Base64.getDecoder()
          .decode(encoded);
```

## Variants

```text
Basic
URL-safe
MIME
```

## Important

Base64 is **encoding**, not encryption.

## Trap

Never present Base64 as a security mechanism for secrets.
