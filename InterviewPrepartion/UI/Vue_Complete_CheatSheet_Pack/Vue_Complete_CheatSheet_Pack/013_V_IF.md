# v-if

## What / Why

Conditionally mounts/unmounts content.

## Mental Model

```text
<div v-if='visible'>
```

## Example / Recall

```vue
<script setup lang="ts">
// Minimal recall area for: v-if
</script>

```

## When to Use

Use when branch presence really changes.

## Common Mistake / Interview Trap

Frequent toggling may favor v-show.
